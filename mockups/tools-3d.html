立體機台：四種畫法TOOL DEPTH · FOUR WAYS TO DRAW THE SAME BAY

同一個 ETCH 區角落（左起 ETCH-05、告警中的 ETCH-07、WET-02、STK-01，中間站著一位兔寶寶裝工程師當比例尺），用四種方式畫。最上面是目前遊戲裡的樣子，下面三種都還是像素、黑色機身、滿滿的閃爍 LED，只差在立體感怎麼做。

The same corner of the etch bay, drawn four ways. The top one is what the game draws today. The other three keep the pixel art, the black tool bodies and the blinking LEDs, and differ only in how they add depth.

現況：薄正面CURRENT · THIN FRONT

頂面加 10px 正面，正面和頂面顏色幾乎一樣，看起來像貼在地上的板子。 / A top face with a 10px front in nearly the same color, so the tools read as flat plates on the floor.

A

厚機身THICK BODY · 3/4 TOP-DOWN

  • LOOK 看起來

    正面加高、頂面前緣一條亮邊、右下有落地陰影，腔體是往下凹的槽。像站在機台前一步往下看。

    A taller front, a bright top edge, a cast shadow, and chambers set into the top. Like looking down from one step away.

  • CHANGE 改動

    只改機台的繪圖程式。佔地格、碰撞和點擊範圍都不用動。

    Only the tool drawing code changes. Footprints, collisions and click areas stay as they are.

  • TRADE-OFF 取捨

    立體感中等，風險最低，和人物、地圖的視角最搭。

    Medium depth and the lowest risk. It matches the characters and map best.

B

斜角側面OBLIQUE · SIDE FACE SHOWS

  • LOOK 看起來

    頂面往右上斜，多看得到右側面，側面也有 LED。像桌上的小模型。

    The top leans up and to the right, so the right side shows, with LEDs on it too. Like a desk model.

  • CHANGE 改動

    要新增斜切的畫法；桌子、置物櫃、咖啡機也得跟著斜，不然視角會打架。

    Needs a new sheared drawing helper. Desks, lockers and the coffee machine have to follow, or the angles clash.

  • TRADE-OFF 取捨

    立體感最強，但人物和地板是正俯視，混在一起最不協調。

    The strongest depth, but it clashes most with the straight top-down characters and floor.

C · 推薦 RECOMMENDED

多層次LAYERED RELIEF

  • LOOK 看起來

    A 的機身，再讓腔體、晶圓盒、燈號塔各自凸起、有自己的影子；LED 會在地上映出一點光。

    A's body, plus raised chambers, FOUPs and signal tower, each with its own shadow. The LEDs throw a little light on the floor.

  • CHANGE 改動

    和 A 一樣只改繪圖，但細節多一倍；燈號塔變高，頭上的提示箭頭要往上挪幾格像素。

    Drawing code only, like A, with about twice the detail. The tower is taller, so the overhead marker moves up a few pixels.

  • TRADE-OFF 取捨

    最精緻、最像真的機台，視角也和 A 一樣協調；代價是畫面比較忙。

    The most detailed and the closest to real tools, with A's matching angle. The cost is a busier screen.

選好之後只會動機台的繪圖（和燈號塔高度），故事引擎那條線照常進行，不受影響。也可以混搭，例如「C 的凸起腔體，但不要地上反光」。

Once you pick, only the tool drawing (and the tower height) changes; the story-engine work carries on unaffected. Mixing works too, for example “C's raised chambers without the floor glow”.
