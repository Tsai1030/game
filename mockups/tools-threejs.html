  • LOOK 看起來

    真正有深度：機台擋住後面的人、陰影落在地上、ETCH-07 的紅光照亮地板。「像素 3D」保留顆粒感，「平滑 3D」比較像現代 3D 遊戲。

    Real depth: tools hide what's behind them, shadows fall on the floor, and ETCH-07's red alarm lights the ground. Pixel 3D keeps a chunky pixel feel; Smooth 3D looks like a modern 3D game.

  • CHANGE 改動

    只換「畫面」那一層：地圖、機台、人物改成 3D 繪製。遊戲邏輯、劇情、存檔、對話框和機台視窗都不用動。點擊走路要改成 3D 點選。

    Only the drawing layer changes: maps, tools and characters become 3D. Game logic, story, saves, dialogue and tool windows stay as they are. Click-to-walk moves to 3D picking.

  • TRADE-OFF 取捨

    畫面會多一個約 600 KB 的函式庫，手機效能要另外調。程式畫的像素機台要重做成 3D 模型。工作量大約一個里程碑。

    Adds a ~600 KB library and needs separate tuning for phones. The code-drawn pixel tools get rebuilt as 3D models. Roughly one milestone of work.
