# M1-3D Renderer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

> Chinese version for the owner: [2026-10-21-m1-3d-renderer.zh-TW.md](2026-10-21-m1-3d-renderer.zh-TW.md). This English file is the canonical plan.

**Goal:** Replace the Phaser 2D world view with a three.js "Smooth 3D" world, as approved by the owner from `mockups/tools-threejs.html`. Everything that isn't drawing stays as it is: story, saves, movement, travel, triggers, dialogue and tool windows.

**Architecture:**
- **`WorldModel` (testable):** a pure three.js scene graph built from the current map data (`MAP`, `T`, `OBJ`, `NPC`). It owns the models, LEDs, markers and lights, and has `update(t, dt)` for animation. No WebGL, so tests can build and inspect it.
- **`WorldView` (glue, not unit-tested):** owns the `WebGLRenderer`, bloom composer, orthographic follow camera, pointer picking, the frame loop and the fade overlay. It replaces `WorldScene.ts` and Phaser.
- **The core stays:** `Mover` keeps its pixel-based logic (1 tile = 16 px), and the view converts to world units (1 tile = 1 unit).

**Tech Stack:**
- Adds `three` 0.160.0 and `@types/three` 0.160.0 (the version the prototype used), installed with `bun add` only.
- Removes `phaser`.
- Everything else is unchanged: Bun 1.4.3, Vite 6.4.3, TypeScript 5.9.3, yaml 2.9.1, happy-dom 20.14.5.

**Spec:**
- `docs/03-spec.en.md` §0 decisions 7 and 8, §2.1, §2.5 and §8. Task 1 updates these sections.
- Visual reference: `mockups/tools-threejs.html`, Smooth 3D style: black metal bodies with rim edges, instanced LEDs, bloom, directional light with shadows, and a red point light under an alarming tool.

**Sequencing:** this plan runs after M1-2a is merged and before M1-2b. That way M1-2b's new characters and meeting scenes are built once, in 3D.

## Global Constraints

- Everything from the earlier plans still applies: Bun only, no player-visible text in `.ts`, `{ zh, en }` data, TDD, and the attribution line on commits.
- **World units:** 1 tile = 1 unit. Map x is world +x, map y is world +z, and height is +y. The floor is at y = 0.
- **Heights** (top of the body in units). The relative proportions come from the prototype:

  | Group | Heights |
  |---|---|
  | Tools | etch, cvd, litho 1.5 · met, track 1.3 · wet 1.0 · stk 3.0 |
  | Furniture | desk 0.75 (monitor top 1.25) · table 0.75 · bench 0.45 · bed 0.5 · sofa 0.8 · booth 1.4 · vending 1.9 · locker 1.9 · coffee 1.5 · board 1.6 · screen bottom 0.6, top 1.8 · gate 1.0 · plant 0.9 |
  | People | 1.4 tall, inside a 0.7 × 0.7 footprint |
  | Walls | a wall tile with floor directly south of it is a back wall, 1.8 tall. Every other wall is 0.6, so the 3/4 camera never loses the player behind one |
  | Glass `g` | a 1.2-tall pane at opacity 0.18 |
- **Camera:**
  - Orthographic, with a fixed 3/4 direction: offset (+6, +20, +16) from its target.
  - Half-height 6.5 units when the stage is ≥ 700 px wide, 5.5 below that.
  - Follows the player with a lerp of 0.15 per frame at 60 fps, clamped so the target stays inside the map rectangle.
- **Look:**
  - Body `0x0f1118` (metalness 0.6, roughness 0.4), tops `0x181b27`, edge lines `0x4a5170`.
  - LEDs use the existing `LEDC` colors with `toneMapped: false`.
  - Bloom: strength 0.95, radius 0.45, threshold 0.55.
  - Hemisphere light 0.55, directional light 1.4 with shadows, ACES tone mapping at exposure 1.15.
- **Quality:** pixel ratio is at most 2, or at most 1.5 below 700 px. The shadow map is 2048, or 1024 below 700 px.
- **Reduce motion:** no blinking, no running lights, no fades, and the worker and OHT stand still. This matches the 2D build.
- **Map changes:** a DOM `#fade` overlay animates opacity 0 → 1 → 0 over 200 ms each way. With Reduce motion it is instant. The location banner is unchanged.

## Review Focus

1. **Clicking a tall object in front of the floor** (for example the stocker's front, or a person standing in front of a desk) targets that object, never the floor tile behind it. Tested in Task 7.
2. **Clicking near the map edge:** the camera clamp never shows a blank strip beyond the walls that a click could land in. A click outside the map does nothing. Tested in Task 7.
3. **The scene for the map you're on after a map change or Continue:** old meshes and listeners are disposed, so there are no doubled frame loops or input handlers after several changes. Tested in Task 6 (model disposal) and Task 9 (one loop).
4. **NPCs appearing or disappearing mid-scene** (flag changes, warps): models are added and removed without leaving ghosts, and an NPC standing on the player's tile is still drawn. Tested in Task 6.
5. **Phones (narrow stage):** the quality settings apply, the canvas fills the stage without horizontal scroll, and touch taps pick like clicks. Tested in Task 9 (settings function) plus the manual check.

### Task 9: WorldView and removing Phaser

**Files:**
- Create `game/src/world3d/view.ts`.
- Modify `game/src/main.ts`.
- Delete `game/src/game/WorldScene.ts`, `game/src/game/viewport.ts`, the 2D world painters (`render/tools.ts`, `render/furniture.ts`, `render/oblique.ts`, `render/tiles.ts`, `render/person.ts` drawing, `render/oht.ts`), and the tests that only cover them. `render/portraits.ts`, `render/palette.ts` and `render/paint.ts` stay because the dialog portraits and the colors still use them.
- Remove Phaser with `bun remove phaser`.

**Interfaces:**
- **Produces:** `class WorldView`:
  - `constructor(stage: HTMLElement)`
  - `start(): void` and `rebuild(): void`
- **What `WorldView` does:**
  - Creates the renderer and composer: `RenderPass`, `UnrealBloomPass`, `OutputPass`.
  - Applies `quality()` and resizes with a `ResizeObserver` on `#stage`.
  - Runs one `requestAnimationFrame` loop. Each frame it:
    - runs the shower timer;
    - calls `mover.tick` with `held` and `busy`;
    - calls `pumpQueue()`;
    - calls `refreshNpcs(S)` and then `model.syncNpcs()`;
    - updates the prompt and the location;
    - updates the camera, then the model;
    - renders.
  - Pointer: `pointerdown` on the canvas: `advanceScene()` when the dialog is open, otherwise `pickAt` → `mover.click`.
  - Fader: `setFader((go, done) => fadeOut(200) → go() → rebuild() → fadeIn(200) → done())`.
  - `on('reset')`: `mover.reset()` plus `rebuild()` if the map changed.
- **`main.ts`:** creates one `WorldView`. There is no Phaser boot and no `viewport.ts`.
