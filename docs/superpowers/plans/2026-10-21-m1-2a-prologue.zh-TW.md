# M1-2a 序章實作計畫

> 給負責人看的中文版。正式版本以英文檔 [2026-10-21-m1-2a-prologue.md](2026-10-21-m1-2a-prologue.md) 為準。執行方式：superpowers 的 executing-plans 或 subagent-driven-development，逐項打勾。

**目標：** 從「新遊戲」開始，可以一路玩完整個序章（第一天，S1–S8），接著直接進入現有的第 2 章。為此需要：四張地圖與門的切換、斜角立體家具、三個新角色、取名字，以及「白天／夜班」狀態。

**架構：**
- **地圖是資料：** 每張地圖是一個 `MapDef`，內容包括地圖格子、物件、附條件的 NPC 位置、出口和區域。`data/world.ts` 的匯出（`T`、`MW`、`MH`、`OBJ`、`NPC`、`ACTS`、`BLK`）改成「即時綁定」，`loadMap(id)` 換地圖時一起換掉，大部分呼叫端不用改。
- **換地圖：** 走 `game/travel.ts`。它負責改狀態，再透過事件通知 `WorldScene` 淡出、用該地圖的貼圖重建畫面、淡入。
- **劇情：** 序章是 YAML 劇情，加上 `triggers:`，在走進某張地圖或某個區域時開始播。效果新增 `time`（設定時間）、`chapter`（換章）、`warp`（瞬移）、`etch`（ETCH-07 狀態）；條件新增 `chapter` 和「多個旗標」。

**技術：** 不變（Bun 1.4.3、Vite 6.4.3、TypeScript 5.9.3、Phaser 3.90.0、yaml 2.9.1、happy-dom 20.14.5），不加新套件。

**依據：**
- `docs/03-spec.zh-TW.md`：§1 範圍、§2.4 存檔、§3 地圖、§4 角色、§5.2 理智、§5.6 問人、§5.9 咖啡、§6 介面（標題畫面、章節卡）、§7.1 序章、§7.2 的 C2-01
- `docs/02-story.zh-TW.md`：§4 角色、§5 序章

**範圍拆分（Claude 的決定，會記在 Task 1）：** M1-2 拆成 M1-2a（本計畫）和 M1-2b（下一份）。M1-2b 包含：阿熊、陳處長、C2-07 到 C2-10、試玩結束卡、完成一章理智 +10、結論錯誤理智 −5、找盟友聊天、劇情效果給的線索也會排 LINE 回報、規格書 §9 驗收。

### Task 1：劇本作者防呆

M1-1 最終審查延後的項目。本計畫會新增約 30 段劇情，所以先做。

- **完整檢查：** 新增 `walkBeats`，資料測試用它走遍所有巢狀段落（then、else、選項的 do、回應的 after）和所有問人回答。檢查項目：id 唯一、說話者存在、中英文都不是空的、goto／include 的目標存在。
- **Commit：** `fix(game): guard unknown scenes and script loops; data tests walk every beat`
