> Chinese version for the owner: [2026-10-21-m1-2a-prologue.zh-TW.md](2026-10-21-m1-2a-prologue.zh-TW.md). This English file is the canonical plan.

**Goal:** Make the game playable from New Game through the whole prologue (Day One, S1–S8) and straight into the existing Chapter 2. This needs four maps with door transitions, oblique furniture, three new characters, a name prompt, and a day-versus-night-shift state.

**Architecture:**
- **Maps as data:** each map is a `MapDef` (tile rows, objects, NPC placements with conditions, exits, regions). `data/world.ts` keeps its current exports (`T`, `MW`, `MH`, `OBJ`, `NPC`, `ACTS`, `BLK`) as live bindings that `loadMap(id)` re-points, so most callers do not change.
- **Map changes:** go through `game/travel.ts` (pure state change plus a bus event). `WorldScene` reacts by fading and restarting with per-map textures.
- **Story:** the prologue is YAML scenes plus `triggers:` that start a scene when you enter a map or area. Effects gain `time`, `chapter`, `warp` and `etch`, and conditions gain `chapter` and multi-flag checks.

**Tech Stack:** unchanged. Bun 1.4.3, Vite 6.4.3, TypeScript 5.9.3, Phaser 3.90.0, yaml 2.9.1, happy-dom 20.14.5. No new dependencies.

**Spec:**
