# M1-3D 3D 畫面實作計畫

> 給負責人看的中文版。正式版本以英文檔 [2026-10-21-m1-3d-renderer.md](2026-10-21-m1-3d-renderer.md) 為準。

**目標：** 把 Phaser 的 2D 世界畫面換成 three.js 的「平滑 3D」（負責人 2026-10-21 從 `mockups/tools-threejs.html` 選定）。畫面以外的部分全部不動，包括劇情、存檔、移動、換地圖、觸發劇情、對話框和機台視窗。

**架構：**
- **`WorldModel`（可以測試）：** 用目前的地圖資料建出 three.js 場景，包括地板、牆、機台、家具、人物、LED、標記、燈光，並負責動畫。它不需要 WebGL，所以測試可以直接建出場景來檢查。
- **`WorldView`（膠水層）：** 負責 WebGL 繪圖、發光效果、跟著玩家的斜俯視相機、點擊選取、每格的更新、換地圖的淡入淡出。它取代 `WorldScene.ts` 和 Phaser。
- **角色移動的邏輯不變：** 還是以像素計算（1 格 = 16 px），畫面換算成 3D 座標（1 格 = 1 單位）。

**套件：**
- 新增 `three` 0.160.0 和 `@types/three` 0.160.0（試作用的同一版），一律用 `bun add`。
- 移除 `phaser`。
- 其他不變。

**時機：** 等 M1-2a 合併後，在 M1-2b 之前做。這樣 M1-2b 的新角色和會議室劇情只要用 3D 做一次。

## 全域限制

- 先前計畫的規則照舊：只用 Bun、文字不寫死在 `.ts`、資料用 `{ zh, en }`、TDD、commit 附署名。
- **座標：** 1 格 = 1 單位；地圖的 x 對到 3D 的 +x，地圖的 y 對到 +z，高度是 +y，地板在 y = 0。
- **高度**（比例沿用試作）：

  | 類別 | 高度 |
  |---|---|
  | 機台 | ETCH、CVD、LITHO 1.5 · MET、TRACK 1.3 · WET 1.0 · STK 3.0 |
  | 家具 | 桌子 0.75（螢幕頂 1.25）· 會議桌 0.75 · 長椅 0.45 · 床 0.5 · 沙發 0.8 · 崗亭 1.4 · 販賣機 1.9 · 置物櫃 1.9 · 咖啡機 1.5 · 白板 1.6 · 投影幕（下緣 0.6、上緣 1.8）· 閘門 1.0 · 盆栽 0.9 |
  | 人物 | 高 1.4，佔 0.7 × 0.7 |
  | 牆 | 南邊緊鄰地板的牆是「後牆」，高 1.8；其他牆都是 0.6，斜俯視的相機才不會被牆擋住玩家 |
  | 玻璃 | 1.2 高、透明度 0.18 |
- **相機：**
  - 正交投影，固定斜俯視（從目標點偏移 (+6, +20, +16)）。
  - 畫面寬 ≥ 700 px 時半高 6.5 單位，窄螢幕 5.5。
  - 平滑跟著玩家，範圍限制在地圖內。
- **外觀：**
  - 黑色金屬機身，頂面略亮，邊線 `0x4a5170`。
  - LED 用現有的顏色並發光；發光強度 0.95。
  - 環境光加平行光，平行光有陰影。
- **畫質：** 解析度倍率最多 2（窄螢幕最多 1.5），陰影解析度 2048（窄螢幕 1024）。
- **減少動態：** 不閃、沒有跑馬燈、不淡入淡出，人物和天車停住，跟 2D 版一樣。
- **換地圖：** 用一層 DOM 遮罩淡出、淡入，各 200 ms；「減少動態」時直接切換。地點名稱橫幅不變。

## 審查重點

1. **點擊高的東西**（例如倉儲機正面、站在桌子前的人）：選到的是那個東西，不是它後面的地板。（Task 7 測）
2. **在地圖邊緣點擊：** 相機不會露出牆外的空白；點到地圖外面沒有反應。（Task 7 測）
3. **換地圖或「繼續」之後：** 舊的模型和事件都清掉，換幾次地圖都不會出現兩個更新迴圈或兩份輸入。（Task 6、9 測）
4. **劇情中 NPC 出現或消失**（旗標改變、瞬移）：模型正確增減，不留殘影；跟玩家站同一格的 NPC 照樣畫出來。（Task 6 測）
5. **手機（窄畫面）：** 套用手機畫質，畫面填滿舞台、不會橫向捲動，點螢幕跟點滑鼠一樣能選取。（Task 9 加手動檢查）

### Task 1：規格書決策與換套件
- **規格書（中英兩版）：**
  - 第 0 節第 7、8 項改成「three.js 平滑 3D（負責人 2026-10-21 選定）」。
  - §2.1 技術改成 three 0.160.0。
  - §2.5 改成斜俯視跟隨相機。
  - §8 改成 3D 模型；頭像維持 2D。
- **路線圖：** 在 M1-2b 前面加一列 M1-3D。
- **套件：** `bun add three@0.160.0`、`bun add -d @types/three@0.160.0`。
- **測試：** three 鎖定在 0.160.0。

### Task 2：座標、材質、地板與牆
- **座標換算：** `toWorld`（像素 → 單位）。
- **共用材質：** 地板用一張畫布貼圖（沿用 2D 的地板顏色）。
- **`buildGround`：** 地板、合併後的牆（後牆 1.8、其他 0.6）、玻璃、風淋室門框。門格不放牆。
- **測試：**
  - 每個牆格剛好被一塊牆蓋住，門和風淋室沒有被蓋。
  - 牆高只有 1.8 和 0.6 兩種。

### Task 3：機台模型、LED、狀態
- **照試作移植：**
  - 機身、腔體；PM 視窗（ETCH-07 的 PM-B 告警時紅色閃爍，停機時琥珀色）。
  - 晶圓盒、各機種的細節。
  - 燈號塔、跑馬燈。
- **LED：** 全部共用一個 InstancedMesh；位置用機台 id 當種子固定下來，只有 ETCH-07 有紅燈（跟 2D 規則相同）。
- **測試：**
  - 模型在佔地格內（正面可以多 0.6，給 load port）。
  - 高度符合表格。
  - LED 都貼在機身表面、每次產生都一樣。
  - 告警時 PM-B 紅暗交替。
  - 減少動態時完全不變。

### Task 4：家具模型
- 每種家具都有模型。
- **會動的部分：**
  - PE 工作站的螢幕在拿到 SPC 線索前閃紅。
  - 置物櫃裡掛著無塵衣（還沒穿上時）。
  - 咖啡機的紅燈會閃。
- **測試：**
  - 每種家具都在佔地格內，高度符合表格。
  - 工作站紅屏在拿到線索後停止。
  - 置物櫃的無塵衣在沒穿時看得到。

### Task 5：人物
- **外觀：** 依現有的外觀表做出 3D 人物：身體、腿、頭髮或帽子、臉、兔寶寶裝的頭套和面罩、領帶、手套。
- **外觀表搬家：** 把外觀表從 `render/person.ts` 搬到 `data/looks.ts`，因為 Task 9 會刪掉前者。
- **動作：** 面向四個方向；走路時手腳擺動。
- **測試：**
  - 每種外觀都在 0.7 × 0.7 × 1.4 內。
  - 面向對應的旋轉角度正確。
  - 站著時不擺動。

### Task 6：組合整張地圖
- **`WorldModel` 會依目前地圖建出：** 地板、物件、LED、NPC、玩家、燈光、天車（M03）、目的地框、互動箭頭。
- **其他功能：**
  - 告警的機台前面放一盞紅色點光源。
  - NPC 清單變了就增減人物模型。
  - `dispose()` 會清空所有東西。
- **測試：**
  - M03 每個可互動物件都可以點選，NPC 一人一個，有天車。
  - M04 沒有天車也沒有機台。
  - NPC 依旗標增減，不留殘影。
  - 清除後場景是空的。
  - 玩家位置換算正確。

### Task 7：相機與點擊選取
- **相機：** 斜俯視正交相機，平滑跟隨並限制在地圖內。
- **`pickAt`：**
  - 先用射線找可點選的模型，最近的那個優先。
  - 沒點到模型就算地板，回傳像素座標。
  - 點到地圖外面回傳 null。
- **`Mover.click`：** 可以直接帶入點到的物件；舊的 2D 判定（`pick`、`VISUAL_TOP`）移除。
- **測試：**
  - 點 ETCH-07 選到 ETCH-07。
  - 點倉儲機正面的中段選到 STK-01，不是後面的地板。
  - 點地板 (3,5) 拿到那一格。
  - 點地圖外面沒有反應。
  - 相機不會跑出地圖。

### Task 8：淡入淡出遮罩、畫質設定
- **`quality(畫面寬, 裝置倍率)`：** 照全域限制回傳解析度倍率、陰影大小、是不是窄畫面。
- **`fadeOut`／`fadeIn`：** 減少動態時立刻完成。
- **測試：**
  - 400 px 寬、裝置倍率 3 → 倍率 1.5、陰影 1024。
  - 減少動態時遮罩完全不出現。

### Task 9：WorldView 上線、移除 Phaser
- **`WorldView`：**
  - 建立 WebGL 畫布和發光效果。
  - 跟著舞台大小調整。
  - **只跑一個**每格更新迴圈：風淋、移動、劇情排隊、NPC 更新、互動提示、相機、模型、繪圖。
  - 點擊：對話中就推進對話，否則選取並走過去。
  - 換地圖時淡出、重建、淡入。
- **刪除：** `WorldScene.ts`、`viewport.ts`、2D 世界的繪圖檔，以及只測它們的測試。頭像、顏色、點陣字保留（對話框還在用）。
- **移除套件：** `bun remove phaser`。
- **測試：** 原始碼裡沒有人 import phaser，`package.json` 也沒有。
- **檢查：** 建置成功，檔案比 Phaser 版小。
