# M1-1 劇情引擎 實作計畫

> 這是給專案負責人看的中文版。執行時以英文版 [2026-10-20-m1a-story-engine.md](2026-10-20-m1a-story-engine.md) 為正本，兩者內容相同。

**目標：** 做出 M1 需要的劇情引擎：
- 理智值
- 話術辨識與 PUA 圖鑑
- 證據簿
- 關係值、問人、四種回應
- 劇本執行器和相關介面

目前第 2 章所有對話都改由新引擎播放。另外加上兩段 LINE 回報劇情（C2-03、C2-06），讓證據簿第一次有真正的內容。

**做法：**
- **純邏輯核心：**
  - 劇本是 YAML 的「段落（beat）」清單。
  - 純邏輯的 `ScriptRunner` 依照遊戲狀態逐段執行，產出畫面（台詞、選項、卡片、結束）和事件（理智歸零、解鎖圖鑑、新增證據）。
  - 規格書裡的數字都寫在新的純邏輯系統裡（理智、證據、關係、回應）。
- **介面層：**
  - `ui/scene.ts` 把執行器接到對話框，負責選項、「？」辨識選單和「記下」按鈕。
  - `ui/cards.ts` 顯示全螢幕卡片。
  - 遊戲裡原本呼叫 `say()` 的地方，全部改成 `playScene(id)`。

**範圍切分（Claude 的決定）：**
- **M1-1（這份計畫）：** 引擎與系統。
- **M1-2（下一份計畫）：** 地圖、新 NPC、序章 S1–S8、第 2 章晨會（C2-07～C2-10）、試玩結束卡，以及規格書第 9 節的驗收。

## 全域限制

M0 的規則全部沿用：只用 Bun、版本鎖定、`.ts` 裡不寫玩家看得到的文字、資料用 `{ zh, en }`、測試先行、commit 加署名。新增的規則如下：

- **理智值：**
  - 範圍 0–100，開始時 80。
  - 辨識正確時，該次損失減半並無條件捨去：−10 變 −5，−15 變 −7，−5 變 −2。
  - 第一次歸零進入「強制請假」，理智回到 40；第二次歸零進入「燃盡」結局。
- **話術辨識：**
  - 每句台詞只能猜一次。
  - 猜對：損失減半，並解鎖該張卡。
  - 猜錯：沒有懲罰，也沒有減傷。
- **圖鑑 v0.1：** 7 張卡，依序是：
  1. 雙重束縛
  2. 否定人格
  3. 拿人比較
  4. 大家庭
  5. 為你好
  6. 搶功
  7. 煤氣燈
- **證據簿：** 標了 `evidence` 的台詞自動記錄；任何台詞都可以手動「記下」。每筆證據包含 ID、時間、來源（對話／LINE／會議）、說話者和中英文內容。
- **關係值：** 範圍 −100～100。初始值：王經理 0、Kevin 10、阿哲 10、芳姐 20、Amy 0、大熊 0。
- **問人：** 選「先說我查過什麼」時，有效關係值 ＋15。≥20 完整回答，0–19 部分回答，<0 拒答。
- **四種回應（理智／對方關係／盟友關係）：**

  | 回應 | 理智 | 對方關係 | 盟友關係 |
  |---|---|---|---|
  | 吞下去 | −3 | ＋5 | 0 |
  | 澄清事實（有證據） | 0 | −5 | 0 |
  | 澄清事實（沒證據） | −3 | −5 | 0 |
  | 設界線 | ＋5 | −10 | 0 |
  | 找人討論 | ＋5 | 0 | ＋5 |

- **存檔：** 沿用同一個 key，版本升到 v2。M0 的 v1 存檔自動升級並補上預設值。

## 審查重點

1. **你瀏覽器裡現有的 M0 存檔：** 按「繼續」能正常讀到，理智是 80、關係值是預設值，不會被當成損壞。（Task 1）
2. **劇情播到一半重新整理：** 會從那一段劇情的開頭重播，效果不會重複套用。劇情進行中暫停定時存檔。（Task 6）
3. **劇情中途理智歸零：**
   - 第一次跳出強制請假卡，劇情乾淨結束、對話框不會卡住，然後繼續玩。
   - 第二次進入燃盡結局，清除存檔並回到標題畫面。（Task 5、8）
4. **選項或辨識選單開著時切換語言：** 文字立刻換語言，選項和選單都還能用。（Task 6）
5. **機台視窗開著時拿到會觸發 LINE 回報的線索：** 劇情會等視窗關掉才播，而且只播一次。（Task 9）

### Task 1：遊戲狀態 v2 與存檔升級
- **新增欄位：** 理智、歸零次數、關係值、已解鎖圖鑑、證據、劇情旗標、目前劇情。
- **存檔：** v1 存檔自動升級；v2 存檔每個新欄位都要驗證。
- **測試：**
  - M0 存檔能讀到，而且值都是預設值。
  - v2 存讀一次，內容一致。
  - 理智 101、歸零 3 次、關係 200、不存在的圖鑑 ID、證據缺英文、旗標不是字串，都判定為損壞。

### Task 2：理智值規則
- **函式：** `halve`（減半捨去）、`applySanity`（夾在 0–100、回報是否歸零）、`zeroOutcome`（第一次請假，之後燃盡）。
- **測試：** 涵蓋全域限制裡的數值。

### Task 3：圖鑑資料
- **內容：** 7 張卡，每張有中英文的名稱、「這是什麼」和「可以怎麼做」，文字來自故事線第 9 節。
- **語系 key：** 新增圖鑑相關的 key，例如「看穿了：{name}」「好像不是這個……」。
- **測試：** 7 張卡都有，雙語都不是空的。

### Task 4：證據、關係、回應規則
- **證據：** 同一筆不重複記錄，依時間排序；可以查「是否全部到手」和「到手幾筆」。
- **關係：** 夾在 ±100；問人的三段結果。
- **回應：** 照上表回傳數值。

### Task 5：劇本格式與執行器
- **段落類型：**
  - 台詞（可帶話術、理智變化、證據標記）
  - 選項（可設條件，條件不符時顯示為不可選）
  - 四種回應
  - 問人
  - 條件分支
  - 效果
  - 腳本證據
  - 卡片
  - 跳轉
- **改寫：**
  - 第 2 章對話改寫成新格式。王經理的四種情況改用條件分支，原本寫在程式碼裡的判斷搬進劇本。
  - 新增 `c2_report_spc`：證據 E-C2-01、E-C2-02，你回報的 LINE 和王經理的回覆。
  - 新增 `c2_report_ring`：證據 E-C2-03、E-C2-04，你回報 focus ring 和王經理回「嗯。」。
- **測試（用測試專用的劇本）：**
  - 逐段執行。
  - 條件選項顯示為不可選。
  - 理智扣減，以及辨識正確後減半。
  - 每句只能猜一次。
  - 自動證據和手動記下。
  - 跳轉和分支。
  - 沒證據時澄清的效果。
  - 問人的三種結果和旗標。
  - 第一次歸零理智回到 40；第二次歸零燃盡並結束劇情。

### Task 6：對話框劇情播放
- **新增：** `playScene`、`queueScene`（等不忙時再播，重複的不會排兩次）、`pumpQueue`。
- **對話框：** 加上「？」辨識鈕、圖鑑選單、「記下」鈕、選項按鈕。
- **存檔：** 劇情開始時先存一次（記錄目前劇情），進行中暫停定時存檔，結束後再存。
- **測試：**
  - 選項可以點，條件不符的選項不可點。
  - 「？」只出現在有話術的台詞。
  - 猜對：減傷並顯示提示；猜錯：「？」消失。
  - 「記下」會寫入證據簿。
  - 切換語言時選項和選單都會跟著換。
  - 劇情中途不會寫入存檔。
- 舊的 UI 測試改用 `playScene`。

### Task 7：理智條、證據簿、圖鑑視窗
- **HUD：** 理智條（數字和長條）、證據簿按鈕（解鎖前隱藏）、圖鑑按鈕；快捷鍵 J／K。
- **證據簿：** 依時間排序，可以依來源篩選，沒有證據時顯示空狀態。
- **圖鑑：** 7 張卡；未解鎖顯示「？？？」；點開看說明；切換語言會重畫。

### Task 8：卡片、強制請假、燃盡
- **全螢幕卡片：** 可以用空白鍵、Enter 或點擊關閉；切換語言會重畫。
- **強制請假：** 卡片內容是「隔天群組裡，王經理：『請假？大家都在拚耶。』」，關掉後劇情繼續。
- **燃盡結局：** 卡片內容是「這不是你的錯。休息一下吧。」，關掉後清除存檔，回到標題畫面。
- **測試：** 理智、歸零次數、存檔清除、回到標題各一次。

### Task 9：接進遊戲
- **改用劇情：** 和 NPC 說話、查看桌子、換無塵衣、泡咖啡、結論的結果，全部改成播劇情。
- **LINE 回報：** 第一次拿到 `spc` 和 `ring` 線索時，排入對應的 LINE 回報劇情。
- **開始與繼續：** 新遊戲播開場；「繼續」時如果存檔停在某段劇情，就從那段的開頭重播。
- **測試：**
  - 和 Kevin 說話會拿到線索。
  - 有 3 條線索時，王經理會說「證據夠了」。
  - 視窗開著時拿到線索，關掉視窗後 LINE 回報播一次，證據簿出現 E-C2-01、E-C2-02，不會重播。

  2. 拿到 SPC 線索、關掉 PE 工作站後，LINE 回報播一次，證據簿裡有 E-C2-01 和 E-C2-02。
  3. 圖鑑視窗顯示 7 張未解鎖的卡。
  4. 有選項顯示時切換語言，選項會跟著換。
  5. 重新整理後按「繼續」，能接續遊戲。
