## 1. 一句話

在虛構晶圓廠「曦晶半導體 Fab 9」當新進工程師的像素 RPG。走進無塵室打開機台、從 log 裡找出良率兇手，同時在主管的 PUA 話術裡保住自己。

## 2. 目標玩家與平台

| 項目 | 內容 |
|---|---|
| 主要玩家 | 科技業從業者（半導體、電子、面板等），看得懂行話和梗 |
| 次要玩家 | 想知道工程師在做什麼的一般玩家、即將進科技業的學生 |
| 平台 | 網頁瀏覽器；之後可包成 PC 版 |
| 文件語言 | 中文、英文兩版 |

## 3. 設計支柱

1. **真的像在上班：** 走進 Fab、穿無塵衣、過風淋室、走到機台前打開機台畫面。
2. **用證據破案：** 線索來自 SPC、FDC log、耗材壽命、wafer map，不靠猜。
3. **看穿話術：** PUA 是敵人的招式。辨識、記錄、設界線是玩家的武器。
4. **業內幽默：** 用共鳴讓人笑，不說教。

## 4. 畫面風格（已定案）

- 黑色系像素 RPG，俯視角，玩家可以自由走動。
- 介面是黑底白框的像素視窗。
- 場景是夜班暗色調：黑色機台，上面有大量閃爍的 LED 光點和跑馬燈，告警時地板會泛紅光。
- 機台展開後的畫面依類型不同。FDC Log 用琥珀色 CRT 終端機風格。
- 定案原型：[mockups/rpg-fab.html](../mockups/rpg-fab.html)。

## 5. 核心循環

```
值班開始
  → 事件（alarm、OOC、主管訊息）
  → 在 Fab 裡移動調查（打開機台 UI、問人）
  → 收集線索
  → 提交結論
  → 結果：良率、產能、人際後果
  → 下一班
```

劇情層同時進行：

```
話術事件 → 辨識（圖鑑卡片）→ 回應（吞下去／澄清／設界線／找人討論）→ 理智值與關係值變化
```

## 8. 範例關卡：Case 03

- **情境：** 夜班 02:47，SPC 自動 hold 了 N9K417.1，ETCH 段 AEI CD（edge）47.4 nm，超出 UCL 46.5。
- **線索：**
  - SPC 的 OOC 點全部來自 ETCH-07 PM-B。
  - FDC 顯示 RF 反射功率一路升到 38 W。
  - 耗材頁面顯示 focus ring 已用 1,180 h，壽命 1,200 h。
  - Wafer map 呈現邊緣一圈偏高的分布。
  - Kevin 學長透露 PM 被延期。
- **干擾項：** Recipe 沒改過、腔體壓力正常、He flow 正常、ETCH-05 可以當對照組。
- **解答：** ETCH-07 / PM-B / focus ring 耗損到壽命。要有 3 條以上線索才能說服王經理。
- 在故事中是第 2 章，接著就是「晨會搶功」事件。

## 9. 故事概要

新進製程工程師林晶（可改名）在 Fab 9 的第一年。從報到第一天的「不會就去問」和「這也要問？」開始，一路遇到搶功、煤氣燈、三角操作、畫大餅、情緒勒索。最後輪到自己帶新人時，選擇要不要把這一切傳下去。共 5 種結局（含隱藏結局）。

完整內容見 [02-story.zh-TW.md](02-story.zh-TW.md)。

## 10. 調性與敏感議題守則

- PUA 只作為被辨識、被反擊的對象；「同化」路線是壞結局。
- 主管也是系統的一環，不寫成純反派。
- 圖鑑提供正確知識和健康的應對方式；遊戲內附求助資源，上市前依地區查證。
- 公司、人物都是虛構，避免影射任何真實公司或個人。
- 上市前請業內人士審閱製程細節，請心理或勞動專業人士審閱圖鑑內容。
